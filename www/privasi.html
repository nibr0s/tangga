Privasi di Tangga

Terakhir diperbarui: 1 November 2026

Singkatnya: progres belajarmu tersimpan di perangkatmu sendiri. Tangga tidak memakai akun, tidak menampilkan iklan, dan tidak menjual data. Hanya sedikit data yang dikirim ke server Tangga, dan semuanya dijelaskan di bawah.

1. Yang tersimpan di perangkatmu saja

  • Nama panggilan, kelas, kampus dan prodi impian, serta target skor yang kamu isi.
  • Jawaban latihan, streak, kartu, dan pengaturan.

Data ini tidak dikirim ke mana pun. Kalau kamu membuat file cadangan, file itu tersimpan di tempat yang kamu pilih sendiri. Untuk menghapus semuanya: Kemajuan → Pengaturan → Hapus semua data.

2. Yang dikirim ke server Tangga

  • Hitungan pengguna harian. Sekali sehari aplikasi mengirim kode perangkat acak (dibuat di HP-mu, tidak terkait nama atau akun), versi aplikasi, jenis perangkat (web atau Android), dan kelas (11 atau 12). Gunanya untuk tahu berapa orang yang memakai Tangga. Dihapus otomatis setelah sekitar 6 bulan tidak aktif.
  • Laporan dan masukan yang kamu kirim sendiri, bersama kode perangkat dan versi aplikasi. Laporan tentang jawaban Kak Tangga ikut menyertakan jawaban itu dan pertanyaanmu sebelumnya.
  • Pesan ke Kak Tangga. Lihat bagian 3.

Server juga memakai alamat IP untuk membatasi pemakaian berlebihan. Alamat IP disimpan hanya sebagai sandi acak (hash) yang berganti setiap hari, lalu dihapus setelah beberapa hari.

3. Kak Tangga (tutor AI)

  • Kak Tangga adalah AI, bukan manusia. Jawabannya bisa keliru.
  • Saat kamu bertanya, pesanmu (beserta beberapa pesan sebelumnya, materi yang sedang kamu pelajari, dan foto soal kalau kamu mengirimnya) diteruskan oleh server Tangga ke Claude, AI buatan Anthropic, untuk dibuatkan jawaban. Nama panggilanmu tidak ikut dikirim.
  • Server Tangga tidak menyimpan isi obrolan. Yang dicatat hanya jumlah pesan per hari dan ukuran pesan (untuk jatah harian dan biaya).
  • Anthropic memproses pesan sesuai kebijakan privasinya.
  • Pengguna di bawah 18 tahun diminta menyatakan bahwa orang tua atau walinya sudah tahu dan mengizinkan sebelum memakai Kak Tangga.
  • Jangan kirim data pribadi seperti nama lengkap, alamat, nomor HP, nama sekolah, atau foto wajah.

4. Layanan pihak lain yang dipakai

  • GitHub Pages menyajikan situs ini dan file aplikasi Android (kebijakan privasi GitHub).
  • Cloudflare menjalankan server Tangga (kebijakan privasi Cloudflare).
  • Anthropic menjalankan Claude untuk Kak Tangga (lihat bagian 3).

5. Hakmu

Kamu boleh berhenti memakai Tangga kapan saja dan menghapus data di perangkat lewat Pengaturan. Untuk minta data di server (laporan, hitungan harian) dihapus, kirim masukan lewat aplikasi dan sebutkan kode perangkat yang tertera di Pengaturan. Tangga berupaya mematuhi Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi.

6. Keadaan darurat

Tangga adalah aplikasi belajar, bukan layanan bantuan. Kalau kamu sedang dalam bahaya atau ingin menyakiti diri sendiri, bicaralah dengan orang dewasa yang kamu percaya, atau hubungi 112.

7. Kontak

Pertanyaan tentang privasi bisa dikirim lewat Kemajuan → Kirim masukan di aplikasi.
